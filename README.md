# Profil pribadi Fadel

Halaman statis satu kolom dengan tampilan gelap yang terinspirasi dari profil Dott.bio. Tidak perlu framework atau proses build; buka `index.html` di browser untuk melihatnya.

## Personalisasi

- Ubah nama dan deskripsi pendek di bagian `<header class="cover">` pada `index.html`.
- Ganti tautan LinkedIn, GitHub, Instagram, portofolio, dan artikel dengan tautan yang ingin kamu tampilkan.
- Foto sampul dari `IMG_1990.HEIC` sudah disiapkan sebagai `cover-photo.jpg`, dalam ukuran web dan tanpa metadata lokasi. Untuk menggantinya, simpan foto lain di folder yang sama, lalu ubah `src="cover-photo.jpg"` di `index.html`.
- Warna latar, kartu, dan teks bisa disesuaikan di bagian `:root` pada awal CSS.
